Stack pages describe capability slots, not products. Each slot says what the capability must do, how to select for it, and what to avoid.

## Slots

- [Agent Architecture](/SHRINE/stack/agent-architecture/): decompose, delegate, validate, and recover
- [Cost Management](/SHRINE/stack/cost-management/): cost per accepted win, tokens plus human attention
- [Evaluation & Benchmarking](/SHRINE/stack/evaluation/): define the win and measure whether the stack works
- [Harness Selection](/SHRINE/stack/harness/): the interface to the models
- [Memory & Context](/SHRINE/stack/memory/): in-session context, cross-session memory, standing instructions
- [Model Selection](/SHRINE/stack/models/): tiers, routing policy, and gateway
- [Observability & Logging](/SHRINE/stack/observability/): traces, logs, and metrics for agent runs
- [Repository Context](/SHRINE/stack/repository-context/): indexed codebase knowledge for agents
- [Skills & Prompts](/SHRINE/stack/skills/): repeatable workflows, encoded
- [Tool Integration](/SHRINE/stack/tool-integration/): tool design, context cost, and security

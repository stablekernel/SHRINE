Shell or file writes run without a pause

Your settings approve shell commands or file writes without asking, or skip the approval prompt. Judgment moves from the risky step to reading diffs after the fact.

Why this is a finding

  • Found: Bash, Write and defaultMode: bypassPermissions.
  • Each one applies in every project that reads these settings.

Why it is a problem

  • A human checkpoint exists in name only, so out-of-scope writes are found by chance.
  • Approvals that never ask cannot be tuned to the risky steps.

Evidence

  • ~/.claude/settings.json: Bash: blanket shell allow
  • ~/.claude/settings.json: Write: blanket write allow
  • ~/.claude/settings.json: defaultMode: bypassPermissions: bypass or auto-approve default mode

Suggested pivot

Replace blanket allow rules with scoped ones and set the default permission mode back to ask. About 10 minutes.

Keep a scoped allow list for the commands you run every day; anything outward-facing or destructive still asks.

What you gain

Judgment where it countsYou decide at the risky step only
3 entries to scopeEach becomes a narrow allow or a prompt
